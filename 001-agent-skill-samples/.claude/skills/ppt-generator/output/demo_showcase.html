代码示例

Python 生成脚本的核心数据结构：


class PPTGenerator:
    """Anthropic 品牌风格 Web PPT 生成器"""

    BRAND_COLORS = {
        "dark":    "#141413",
        "light":   "#faf9f5",
        "orange":  "#d97757",
        "blue":    "#6a9bcc",
        "green":   "#788c5d",
    }

    def generate(self, content: str, title: str) -> str:
        slides = self.parse_markdown(content)
        html = self.render(slides, title)
        return html  # 单个 HTML 文件，即开即用

技术方案对比

方案 优点 缺点 推荐度
Reveal.js + CDN 轻量、成熟、单文件输出 需手写 HTML 结构 推荐
Slidev Markdown 驱动、Vue 生态 需 Node.js + npm 不推荐
Next.js + MDX 组件化强、可定制 工程化过重 不推荐
纯手写 HTML 完全可控、零依赖 需自建翻页逻辑 备选

工作流程

用户输入 add ppt 后，系统自动执行以下步骤：

Step 1
内容提取
获取最近一轮问答或用户指定的对话内容
Step 2
Markdown 解析
按标题、代码块、列表自动分页，智能识别布局类型
Step 3
品牌样式注入
应用 Anthropic 配色、字体、强调色循环规则
Step 4
生成 HTML 文件
输出单个 HTML，双击即可在浏览器中播放演示
