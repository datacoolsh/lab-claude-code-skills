周例会深度分析

算酷团队

分析背景

基于 2025-12-22 周例会纪要 的深度分析，聚焦两个关键问题：

  • 问题一：资产运营部年底冲刺，能否完成目标？
  • 问题二：供应链部被定义为"公司核心"，实际进展如何？

资产运营部 — 目标与缺口

  • 年度目标：5000 - 6000万
  • 已完成：4000万
  • 缺口：1000 - 2000万
  • 剩余时间：仅 9 天（截至12月31日）

已明确的增量来源

项目金额时间计入2025年？
善哲正贷款600万12月22日能
栢莱资产贷款未明确2026年1月1日不能
5间空商铺出租未明确12月底前视签约
一笔有效资产未明确12月底前视落地

三个关键发现

  • 栢莱资产无法计入2025年 — "开门红1月1号放款"，属于2026年业绩
  • 善哲正600万到账后，仍差400 - 1400万 — 最低目标差400万，上限目标差1400万
  • 剩余弹药模糊 — 商铺出租和有效资产均无明确金额

冲刺结论

  • 最低目标5000万：善哲正到账后差400万，商铺 + 资产需覆盖缺口，难度中等但时间极紧
  • 上限目标6000万：即使所有项目全部落地，仍有较大缺口，年内基本不可能
  • 核心变量：商铺租金收入 + "一笔有效资产"的规模与落地速度

供应链部 — 战略定位 vs 实际状态

  • 温志刚定位："公司核心"，匹配供应链金融
  • 覆盖品类：农产品、冻品、科技品类、有色金属
  • 实际状态：从零搭建的早期阶段
  • 唯一落地计划：1月引进五常大米（员工福利）

六个反常信号

信号具体表现
无人汇报工作汇报环节，供应链部完全缺席
负责人模糊全文未明确负责人（陈敏总疑似）
办公场所未就绪"位于4701，目前人员在4702"
无业绩数据零贸易金额、零合同、零客户
规划即福利4大品类，唯一计划是买大米当福利
能力集中个人供应链知识仅陈敏掌握，未形成团队

判断：尚未实质启动

  • 办公室没搬过去 — 物理空间未独立，团队编制未就绪
  • "搭建贸易"而非"开展贸易" — 用词本身说明还在建设阶段
  • 四大品类全是规划 — 没有任何品类有实际交易记录
  • 与供应链金融是"匹配"关系 — 贸易背景尚未建立

战略级风险

  • 银行业务部每周数亿规模的银票开贴需要真实贸易背景
  • 供应链部无法产生贸易流水 → 贸易合规性承压
  • 供应链金融增量业务缺乏底层资产
  • 公司业务架构中最核心的一环是空的

待确认事项

资产运营部：

  • 商铺出租的预期收入是多少？
  • "一笔有效资产"具体指什么、规模多大？

供应链部：

  • 陈敏是否为正式负责人？
  • 第一笔实际贸易预计何时完成？
  • 当前银行业务的贸易背景由谁支撑？
