# PPT Generator — Web 演示文稿生成器

将 Claude Code 对话内容一键转换为高质量的 Web 演示文稿。

## ✨ 特性

- 🎨 **Anthropic 品牌风格** — 官方配色、字体、排版规范
- 📦 **单文件输出** — 生成的 HTML 可直接分享和播放
- 🚀 **即开即用** — 无需 Node.js，所有依赖通过 CDN 加载
- 💻 **代码高亮** — 支持多种编程语言语法着色
- 📱 **响应式设计** — 适配桌面、平板、手机

## 🎯 快速开始

### 1. 在对话中触发

只需在 Claude Code 对话中输入：

```
add ppt
```

或者：

```
添加ppt
```

### 2. 确认内容

Claude 会询问你要转换的内容：

```
🎯 PPT 生成确认

📄 内容来源：最近一轮问答
   Q: 如何实现用户认证？
   A: [完整回答内容预览...]

📌 建议标题：用户认证实现方案
🗂️  文件名：presentation_20260301_183000.html

是否确认生成？
```

### 3. 打开演示

生成完成后，双击 HTML 文件即可在浏览器中播放！

## ⌨️ 操作说明

在浏览器中打开 PPT 后：

| 操作 | 功能 |
|------|------|
| `→` `↓` `空格` | 下一页 |
| `←` `↑` | 上一页 |

## 🎨 品牌设计规范

本技能严格遵循 Anthropic 官方品牌设计：

### 配色方案

| 颜色 | HEX | 用途 |
|------|-----|------|
| Dark | `#141413` | 主要文本 |
| Light | `#faf9f5` | 背景 |
| Orange | `#d97757` | 主要强调色 |
| Blue | `#6a9bcc` | 次要强调色 |
| Green | `#788c5d` | 第三强调色 |

强调色按 **橙→蓝→绿** 的顺序在幻灯片间循环应用。

### 字体系统

- **标题**：Poppins（≥24pt 时使用，降级到 Arial）
- **正文**：Lora（降级到 Georgia）
- **代码**：JetBrains Mono（降级到等宽字体）

## 📐 内容分页规则

PPT 自动按以下规则分页：

1. **按二级标题分页**：每个 `##` 生成一页
2. **按分隔符分页**：`---` 手动分页
3. **智能分段**：单页超过 300 字自动拆分

### 示例

```markdown
## 第一页标题
内容 A

## 第二页标题
内容 B

---

## 第三页标题（强制分页）
内容 C
```

## 🙋 常见问题

### Q: 生成的 PPT 需要网络吗？

A: 首次打开需要网络加载 CDN 资源（字体、Reveal.js）。加载后浏览器会缓存，离线也能使用。

### Q: 可以修改生成的 PPT 吗？

A: 可以！生成的 HTML 文件可直接编辑。样式在 `<style>` 标签中，内容在 `<section>` 标签中。

### Q: 支持导出 PDF 吗？

A: 支持！在浏览器中打开 PPT，按 `E` 键或在 URL 后添加 `?print-pdf`，然后使用浏览器的"打印到 PDF"功能。

### Q: 如何嵌入图片？

A: 在 Markdown 中使用标准图片语法：`![描述](图片URL)`。建议使用在线图片或 Base64 编码。

### Q: 能自定义配色吗？

A: 可以修改生成的 HTML 文件中的 CSS 变量（`--anthropic-*`），但建议保持品牌一致性。
